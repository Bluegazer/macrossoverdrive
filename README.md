# Macross Overdrive - Web Demo // VF-1 Valkyrie Arcade - Sim

Prototipo web de combate aéreo y mecha en 3D inspirado en *Macross: Do You Remember Love?* y *Macross VOXP*, desarrollado con **Three.js**, **HTML5 Canvas 2D**, **Web Audio API** y **WebRTC (PeerJS)**. 

## Descripción del Juego

Macross Overdrive es un proyecto de fan a fan que recrea la experiencia de combate con el caza VF-1 Valkyrie en distintos entornos y modos de juego. Permite alternar entre un modo **Simulador** (con gestión de calor y físicas tácticas) y un modo **Arcade** (con ayudas de puntería), e incluye soporte para múltiples idiomas (Español, Inglés, Chino y Japonés).

El juego cuenta con diversos teatros de operaciones como la Isla South Ataria, la órbita de Saturno con sus cinturones de asteroides y los interiores del SDF-1 Macross. Ofrece además multijugador online P2P vía PeerJS para duelos 1 vs 1 y combates por escuadrones, con transiciones fluidas entre los modos *Fighter*, *Gerwalk* y *Battroid*, HUD vectorial, múltiples tipos de armamento y compatibilidad con mandos y teclado.

## Estructura del Proyecto

El repositorio distribuye su código en módulos JavaScript (`js/`), modelos 3D (`models/`), recursos de audio y el punto de entrada principal en `index.html`. Se recomienda ejecutarlo mediante un servidor web local si no se desea usar el link online.-
